> x86CSS is a working CSS-only x86 CPU/emulator/computer. Yes, the _Cascading Style Sheets_ CSS. No JavaScript required.

> What you're seeing above is a [C program](https://github.com/rebane2001/x86CSS/blob/mane/c/main.c) that was compiled using [GCC](https://en.wikipedia.org/wiki/GNU_Compiler_Collection) into native [8086](https://en.wikipedia.org/wiki/Intel_8086) machine code being executed fully within CSS.

[Lyra Rebane](https://lyra.horse/) hat einen [x86](https://de.wikipedia.org/wiki/X86-Prozessor) CPU Emulator in – Trommelwirbel 🥁 – CSS gebaut, was absolut verrückt ist. Also im positiven Sinne. Dass das überhaupt geht und das zu machen.
